# Trying Daybar

Daybar is a calendar in your Mac's menu bar. It uses the calendars already on your Mac
(System Settings → Internet Accounts), so add your Google account there first if it isn't.

## Install (once)

1. Download **Daybar-x.y.zip** from the [latest release](https://github.com/purirohan/daybar-releases/releases/latest).
2. Open the zip and drag **Daybar** into **Applications**.
3. Open Daybar. macOS will say it can't check it for malicious software, because it isn't from
   the App Store. Click **Done**, then open **System Settings → Privacy & Security**, scroll down,
   and click **Open Anyway** next to Daybar. You only do this once.
4. Allow calendar access when asked. The calendar icon appears in the menu bar; **⌘1** opens it from anywhere.

## Updates

Daybar checks for new versions once a day and asks before installing. To check right away:
gear menu → **Check for Updates…**

## Meet and Zoom links

Settings → Google → **Connect Google** adds Meet links and sends invites from your account.
Settings → Zoom: paste your personal Zoom link, or **Connect Zoom** for a new meeting each time.
Then type `+meet` or `+zoom` when you add an event, or use the video button on any event.
